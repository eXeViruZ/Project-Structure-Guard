# 01 — Installation

## Requirements

- Unreal Engine 5.7
- Windows, Mac, or Linux
- Editor-only — no runtime dependency

---

## Install from Fab

1. Purchase Project Structure Guard on Fab.
2. Open the Epic Games Launcher.
3. Go to **Library → Fab Library**.
4. Find **Project Structure Guard** and click **Install to Engine** next to your UE 5.7 installation.

---

## Install Manually (ZIP)

1. Download the plugin ZIP from the link provided on the Fab listing.
2. Extract the ZIP. You will get a `ProjectStructureGuard` folder.
3. Copy that folder into one of the following locations:
   - **Engine-wide:** `[UE Install]/Engine/Plugins/ProjectStructureGuard/`
   - **Project-only:** `[YourProject]/Plugins/ProjectStructureGuard/`
4. Restart the Unreal Editor.

---

## Enable the Plugin

1. Open your project in Unreal Editor.
2. Go to **Edit → Plugins**.
3. Search for **Project Structure Guard**.
4. Enable the checkbox.
5. Restart the editor when prompted.

---

## Open the Tool

After restart, open the tool via:

```
Tools → Project Structure Guard
```

The PSG window will dock as a tab in your editor layout.
